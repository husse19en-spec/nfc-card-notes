# بطاقاتي — تطبيق ملاحظات البطاقات عبر NFC

تطبيق أندرويد: عند تقريب بطاقة مصرفية (contactless) من ظهر الهاتف، يتعرّف عليها
التطبيق ويعرض البيانات/الملاحظات التي أدخلتها أنت مسبقاً لتلك البطاقة. وإن كانت
بطاقة جديدة، يفتح لك نافذة لإدخال اسمها وملاحظاتها وحفظها.

## كيف يميّز البطاقة؟
يقرأ رقم البطاقة من الشريحة ليعرف "أي بطاقة هذه"، ثم **يحفظ بصمة مشفّرة (SHA‑256)
للرقم فقط + آخر 4 أرقام** للتعرّف البصري. الرقم الكامل لا يُخزَّن إطلاقاً، وكل شيء
يبقى محلياً على هاتفك فقط (لا إنترنت، لا خوادم).

## طريقة البناء (إنشاء ملف APK)
1. ثبّت **Android Studio** (أحدث إصدار مستقر).
2. من القائمة: `File ▸ Open` واختر مجلد `NfcCardNotes`.
3. اترك الاستوديو يُنزّل Gradle ويُزامن المشروع (Sync) — يتم تلقائياً.
4. لتجربته: وصّل هاتفاً يدعم NFC ثم اضغط **Run ▶**.
5. لإنتاج APK: `Build ▸ Build Bundle(s) / APK(s) ▸ Build APK(s)`.
   ستجد الملف في `app/build/outputs/apk/debug/app-debug.apk`.

## الاستخدام
- افتح التطبيق، فعّل NFC من إعدادات الهاتف، وقرّب بطاقتك من الخلف.
- بطاقة جديدة → أدخل الاسم والملاحظات ثم **حفظ**.
- بطاقة محفوظة → تظهر بياناتها مباشرة، ويمكنك التعديل أو الحذف.
- تظهر كل البطاقات المحفوظة في قائمة داخل الشاشة، ويمكنك فتح أي منها دون تقريبها.

## ملاحظات مهمة
- يعمل مع كثير من بطاقات Visa / Mastercard اللاتلامسية، لكن **ليس كلها**؛ بعض
  البطاقات تتطلب تسلسلاً أعقد ولن تُقرأ. في هذه الحالة تظهر رسالة "تعذّرت القراءة".
- يحتاج هاتفاً يدعم **NFC** (معظم الأجهزة الحديثة).
- استخدمه لبطاقاتك الشخصية فقط.
- اسم الحزمة الحالي `com.example.nfccardnotes` — غيّره قبل أي نشر.
